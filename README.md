# Strata

ノートを、そのノート自身が持つ日付にもとづいて年別のアーカイブフォルダへ移動する Obsidian プラグインです。

アクティブでないノートを退避させたいとき、既存のアーカイブ系プラグインの多くは「アーカイブを実行した日」や「固定の移動先」を使います。Strata は違い、**移動先パスをノートの内容（日付）から動的に決める**ことに主眼を置いています。

## 特徴

- ノート自身の日付から `archive/{YYYY}/` を決定して移動する
- 日付は フロントマター → ファイル名 → タイムスタンプ の順にフォールバックして解決
- 移動には `fileManager.renameFile()` を使うため、**他ノートからのリンクが自動で張り替わる**
- 同名ファイルがあっても上書きせず、` 2`, ` 3` … と連番を付けて退避
- 直前のアーカイブをワンコマンドで取り消せる
- デスクトップ・モバイル両対応（Node.js API 非依存）

## 使い方

### コマンド

| コマンド | 説明 |
|---|---|
| このノートをアーカイブ | アクティブなノートをアーカイブフォルダへ移動します |
| 直前のアーカイブを取り消す | 直前の移動を元に戻します |

いずれも条件を満たさないときはコマンドパレットに表示されません（アーカイブ済みのノートや非 Markdown ファイルを開いているときなど）。

### ファイルメニュー

ファイルエクスプローラやタブの右クリックメニューから「アーカイブ」を選べます（設定でオフにできます）。

## 日付の解決順序

移動先の年は、以下の優先順位で最初に有効な値を採用します。

1. **フロントマターの日付フィールド** — 設定したキー（既定: `date`, `created`, `作成日`）を先頭から走査。`Date` オブジェクト・文字列の両方に対応します。
2. **ファイル名に含まれる日付** — `2026-08-06.md`, `20260806 議事録.md`, `日報 2026_08_06.md` などを認識します。
3. **ファイルのタイムスタンプ** — 作成日時（`ctime`）。設定で最終更新日時（`mtime`）に切り替え可能です。

抽出した年が 1900 未満または 2200 超の場合は無効とみなし、次のフォールバックへ進みます。

## 移動先パス

```
{archiveRoot}/{年}/{ファイル名}.md
```

「月別サブフォルダ」を有効にすると `{archiveRoot}/{年}/{月}/` の 2 階層になります。月はファイル名・フロントマターの日付から取得し、取れない場合は年フォルダ直下に置きます（タイムスタンプから月を捏造することはありません）。

## 設定

| 設定項目 | 既定値 | 説明 |
|---|---|---|
| アーカイブ先フォルダ | `archive` | 移動先のルートフォルダ |
| 日付フィールド | `date, created, 作成日` | 参照するフロントマターのキー（カンマ区切り） |
| 月別サブフォルダ | オフ | 有効時は `年/月` の 2 階層 |
| フォールバックのタイムスタンプ | 作成日時 (ctime) | 日付が取れなかった場合に使うタイムスタンプ |
| ファイルメニューに項目を追加 | オン | 右クリックメニューに「アーカイブ」を表示 |

## 開発

```bash
npm install       # 依存関係のインストール
npm test          # date-resolver の単体テスト (Jest)
npm run dev        # 開発ビルド（watch）
npm run build      # 型チェック + 本番ビルド
```

`src/date-resolver.ts` は Obsidian API に依存しない純粋関数として実装されており、`__tests__/date-resolver.test.ts` で単体テストしています。
